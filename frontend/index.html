How It Works

Three-Stage Verification Workflow

Ensuring academic integrity and verified project submissions across all engineering departments.

1

Student Submission

Student logs in to their dashboard, provides project title, synopsis, tech stack, GitHub repository URL, and screenshot, then submits for faculty evaluation.

2

Faculty Evaluation

Reviewers access the Pending Review queue to inspect the implementation, verify requirements, and either 1-click Approve or Reject with constructive remarks.

3

Live Repository

Approved projects are immediately published to the campus repository where other students and faculty can discover, search, and benchmark project work.
