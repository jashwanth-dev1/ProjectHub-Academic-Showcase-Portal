Problem Statement 4 · Mini Project Showcase Portal

ProjectHub

A centralized, digital academic project repository with faculty approval workflow, rich search & filtering, and domain-wise analytics.

👨‍🎓 Student Role

Project submission, GitHub links, screenshots, real-time approval tracking.

👨‍🏫 Faculty Role

Submissions review, approval / rejection with feedback, domain analytics.

Objective & Challenges

Why ProjectHub is Needed

Engineering students develop multiple projects during their degree, but their work is scattered, lost after semester evaluations, and rarely showcased to juniors, recruiters, or campus visitors.

⚠️ The Challenges

• Lack of centralized digital repository for academic mini projects
• No systematic faculty quality assurance prior to public display
• Difficult to search projects by tech stack, batch, or domain

🎯 The Solution

• Centralized web platform connecting students and evaluators
• Strict 2-tier approval workflow (Pending → Approved / Rejected)
• Real-time search across titles, technologies, and batches

System Architecture

Tech Stack & Database Design

💻 Tech Stack

• Frontend: HTML5, Responsive CSS3, JavaScript (ES6+)
• Backend: Node.js, Express.js REST API
• Database: MySQL 8.0 (Relational tables + Foreign Keys)
• Auth: JWT & Bcrypt password hashing

🗄️ MySQL Database Schema

Table Key Fields
Users userId, name, role (student/faculty), email, password
Projects projectId, title, description, technologies, githubLink, screenshotPath, category, batch, studentId, status
Implementation

Core Modules Delivered

1. Authentication Module

Role-based login and registration for Students & Faculty with bcrypt hashing & JWT tokens.

2. Project Management

Students submit project details, upload screenshots, provide GitHub URLs, and edit before approval.

3. Approval Workflow

Faculty reviews pending submissions, inspects source code, and approves or rejects with constructive feedback.

4. Search & Analytics

Multi-parameter search by tech stack, batch, domain, plus category distribution charts.
